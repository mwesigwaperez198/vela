# DA-VELA FASHIONS

**DA-VELA HOUSE OF ARTS** - African Luxury Redefined

A premium fashion brand from Kampala, Uganda showcasing heritage-inspired luxury designs with a modern editorial aesthetic.

## Features

- **Infinite Video Hero** - Immersive full-screen video experience
- **Ghost Navigation** - Elegant transparent navigation that hides on scroll
- **Serif/Sans Typography** - Refined typographic hierarchy
- **Gallery Collection** - Browse designs by sex, culture, and country
- **Built-in CMS** - Full content management system at `/admin`
- **African Luxury Focus** - Celebrating African heritage and craftsmanship

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Clean HTML/CSS/JS architecture
